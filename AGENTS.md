# Agent guidelines

Instructions for AI coding agents working in this repository.

## Git

- Name branches `feature/<slug>`, where `<slug>` is a short, lowercase, hyphen-separated description of the change, e.g. `feature/config-header`.
- Don't hard-wrap text in commit messages or pull request descriptions. Write each paragraph or list item as a single line and let the tools' word wrapping handle the presentation. Use line breaks only where they carry meaning: after the commit subject line, between paragraphs, and between list items.
